## v0.1.0 - 2026-09-29

Initial release. Budgebell is a fully-local desktop app that nudges you through habits (movement
drills first, general habits too), shows you what to do, and logs what you actually did. Habit
definitions, media and logs stay on your machine: no network calls, no telemetry, no cloud.

### Added

* Tray-only app (menu bar on macOS, status icon on Linux) with an always-on-top corner toast that
  stays up until you mark a habit Done or Skip, expands into a dialog with full instructions, and
  can be snoozed or paused.
* Scheduler with interval and time-of-day triggers, habit rotations, and quiet rules that hold
  nudges back while you are idle, in a call (microphone in use), or in a calendar meeting.
* Local SQLite store for habits and the done/skipped event log, seeded with default content on
  first run, plus a Stats window that summarises the day.
* Local images shown in nudges, served from the app's own media folder.
* Bundled local MCP server (stdio) so an MCP client can list, add, update and disable habits and
  query the log.

### Known limitations

* Builds are unsigned. macOS and Windows will warn on first launch; see the Install section of
  the README.
* macOS is the primary target; Linux support is newer and less exercised. On GNOME the tray icon
  needs the AppIndicator shell extension.
